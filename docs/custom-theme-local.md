# 테마 커스텀 로컬 구현

운영 배포본 16edf98에서 분리한 브랜치. 운영 API/DB에는 적용하지 않았다.

- 배송관리의 흰색 고정 배경과 별도 accent 변수를 기존 테마의 surface/stamp/ink 변수로 통일.
- 화사한 프리셋 피치 크림·민트 가든·라일락 밀크 추가. 기존 프리셋 색상값은 유지.
- 배경·카드·포인트의 HEX 입력 및 색상 선택기, 팬/실제 배송관리 컴포넌트 미리보기.
- 미리보기 중 서버 요청 없음. 저장 버튼에서만 저장. 프리셋 복원도 저장 전까지 미리보기.
- 글자와 포인트색은 대비 4.5:1을 기준으로 자동 산출. 배경과 카드 양쪽에서 기준을 만족하지 못하면 저장 차단. 보정된 포인트색을 UI에 고지.
- 커스텀은 정적 배경 사용. 이미지·사용자 CSS·외부 URL 입력은 받지 않음.
- 기존 accent_color 프리셋 ID는 그대로 보존하고 nullable custom_theme JSONB에 선택 설정만 저장. 조회는 기존 streamer 조회에 포함하며 별도 조회 추가 없음.
- 설정은 해당 streamer PATCH 한 번으로 저장. 동시 편집은 기존 테마 저장과 동일하게 마지막 저장이 반영됨(버전 충돌 보호는 이번 테마 설정에 추가하지 않음).

검증: 팔레트 64조합의 대비/실패 폴백, 잘못된 입력 거부, 프리셋 보존, 로컬 API 인증/저장/복원/다른 계정 격리/옷장 반영, 브라우저 저장 후 새로고침, 모바일 너비, 옷장 회귀 25개, ESLint 및 빌드 통과.

로컬 URL: http://127.0.0.1:4065/aengjyu/settings (비밀번호 1234, 로컬 복제 계정).
팬/배송관리 미리보기는 합성 예시 데이터이며 실제 배송 처리 버튼은 비활성이다. 테마 저장은 로컬 DB에 반영된다. 운영 배포 전에는 실제 팬/배송/후원집계/옷장의 전체 테마 조합과 반투명 기존 테마의 대비를 더 검증해야 한다. 64개 조합 검사를 모든 가능한 RGB 조합 검증으로 해석하지 않는다.
